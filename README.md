# JnU ShebaLink – Local Service Provider Booking Platform

## Overview

JnU ShebaLink is a local service provider booking platform designed to connect users with trusted service providers around Jagannath University. The system allows users to search, compare, and book services easily while helping local service providers manage their work efficiently.

The platform focuses on three core principles:

* Connect
* Secure
* Empower

## Problem Statement

People often face difficulties when searching for local services due to:

* Lack of trusted service providers
* No centralized booking system
* Time-consuming manual communication
* Difficulty accessing emergency services
* Unclear pricing and service information

JnU ShebaLink aims to solve these problems through a secure and user-friendly digital platform.

## Objectives

* Develop an easy-to-use Android application
* Connect users with nearby service providers
* Provide secure booking and communication
* Save users' time and effort
* Increase earning opportunities for local providers
* Ensure transparency through ratings and reviews
* Improve accessibility of local services

## System Modules

### User Module

Allows users to browse services, view provider information, make bookings, track service status, communicate with providers, and submit reviews.

### Provider Module

Enables service providers to manage profiles, pricing, availability, bookings, and customer interactions.

### Admin Module

Provides complete control over the platform, including user management, provider verification, and monitoring of all activities.
